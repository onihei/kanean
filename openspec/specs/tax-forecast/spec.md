# tax-forecast Specification

## Purpose

期中の confirmed 仕訳から年間の税負担（所得税・住民税・個人事業税・消費税）を予測し、
「追加で経費／所得控除を使ったら税額がどう変わるか」の what-if を提示する。
計算は `packages/core` の純関数（年換算・住民税/事業税の概算＋既存の所得税・簡易課税ロジック）に委譲する。
出力は常に**参考値**であり、免責を伴って提示する（`legalRisk:medium`）。
（[docs/roadmap.md] Phase 5 slice11）

## Requirements

### Requirement: 期中実績の年換算による税額予測

システムは open 年度の確定実績を経過月数で年換算し、年間の税負担を予測する SHALL。

#### Scenario: 年間税負担を返す

- **WHEN** `GET /api/tax-forecast` を呼ぶ
- **THEN** 年換算後の事業所得・課税所得・所得税（復興特別所得税を含む）・住民税・個人事業税・消費税と、その合計を返す

#### Scenario: 経過月数の範囲を守る

- **WHEN** 年換算の経過月数が 1〜12 の整数でない
- **THEN** 黙って近似せずエラーとする（入力どおり返すフォールバックを行わない）

#### Scenario: 会計年度が無い場合

- **WHEN** open な会計年度が存在しない
- **THEN** 200 で `forecast: null` を返す（オンボーディング前の正常状態としてエラー扱いしない）

### Requirement: 概算税目の算定

システムは住民税・個人事業税を明示された概算前提で算定する SHALL。

#### Scenario: 住民税を概算する

- **WHEN** 課税所得が正である
- **THEN** 所得割（課税所得 × 10%・切捨て）＋ 均等割 5,000 円を住民税とする

#### Scenario: 課税所得が0以下なら非課税とする

- **WHEN** 課税所得が 0 以下である
- **THEN** 均等割を含めて 0 とする

#### Scenario: 個人事業税を概算する

- **WHEN** 事業所得（青色申告特別控除前・㊸相当）が事業主控除 290 万円を超える
- **THEN** 超過額 × 税率（既定 5%・切捨て）を個人事業税とし、超えない場合は 0 とする

### Requirement: what-if シミュレーション

システムは追加経費・追加所得控除を与えた再計算と、基準予測との差分を返す SHALL。

#### Scenario: 追加経費・控除で再計算する

- **WHEN** `GET /api/tax-forecast?extraExpense=&extraDeduction=` を非負整数（円）で呼ぶ
- **THEN** 当該額を反映した再計算結果と、基準予測との税負担差（delta）を返す

#### Scenario: 不正な値を拒否する

- **WHEN** 負数・小数・指数表記・円整数の安全上限超の値が指定される
- **THEN** 400 を返す

#### Scenario: 未指定は what-if なしとして扱う

- **WHEN** パラメータが未指定または空文字である
- **THEN** what-if を適用せず基準予測のみを返す

### Requirement: 参考値の明示

システムは予測結果に免責文言を含め、UI が常に表示できる形で返す SHALL。

#### Scenario: 免責を返す

- **WHEN** 予測結果を返す
- **THEN** 「確定済み仕訳の年換算による参考値であり、税制改正・自治体・業種等により異なる。申告の判断は税理士に確認する」旨の disclaimer を含める
