## ADDED Requirements

### Requirement: 該当画面を開く外部リンク

システムは自身を `kanean://` スキームの取り扱い先として登録し、外部から渡されたリンクで
**アプリを前面に出して該当画面を表示する** SHALL。リンクの受理はアプリ内の画面遷移に限り、
会計データの変更を伴う操作をリンクだけで実行してはならない。

#### Scenario: 起動中にリンクを開く

- **WHEN** アプリが起動している状態で `kanean://` のリンクが開かれる
- **THEN** ウィンドウが前面に出て、リンクが指す画面が表示される

#### Scenario: 未起動でリンクを開く

- **WHEN** アプリが起動していない状態で `kanean://` のリンクが開かれる
- **THEN** アプリが起動し、リンクが指す画面が表示される

#### Scenario: リンクだけで会計データが変わらない

- **WHEN** 変更操作を示唆するリンクが開かれる
- **THEN** 該当画面を開くにとどまり、利用者の操作なしに会計データは変更されない

#### Scenario: 解釈できないリンクで壊れない

- **WHEN** 未知の経路を指す `kanean://` のリンクが開かれる
- **THEN** アプリは通常の初期画面を表示し、異常終了しない

## MODIFIED Requirements

### Requirement: 配布物の成立

システムは受け取った利用者が追加のランタイム導入なしにインストール・起動できる配布物を提供する SHALL。
配布物には MCP クライアントへ導入するためのバンドル（[[mcp-server]]）を同梱し、
利用者が別途取得する必要がない状態にする。

#### Scenario: 受け取った人が起動できる

- **WHEN** 配布物を受け取った利用者が、Node.js も pnpm も導入していないマシンにインストールする
- **THEN** アプリが起動し、帳簿を作成して仕訳を入力できる

#### Scenario: 署名の警告が出ない

- **WHEN** 配布物を初めて開く
- **THEN** 開発元を検証できない旨の警告なしに起動できる

#### Scenario: MCP バンドルを同梱している

- **WHEN** 配布物からインストールしたアプリで連携の導線を実行する
- **THEN** ネットワークから何も取得することなく、導入用のバンドルが得られる
