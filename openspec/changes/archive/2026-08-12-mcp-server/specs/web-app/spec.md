## MODIFIED Requirements

### Requirement: 設定画面

システムは各種設定として、アプリモード・マスタ管理・事業者設定・帳簿管理・データ管理・
AI クライアント連携を提供する SHALL。

#### Scenario: アプリモードを変更する

- **WHEN** 設定画面でアプリモードを変更する
- **THEN** 変更後の起動導線と UI の露出範囲を説明したうえで保存する
- **AND** `office` から `personal` への変更がアクティブ2冊以上で拒否された場合は、帳簿管理への導線を示す

#### Scenario: マスタを管理する

- **WHEN** 設定画面のマスタタブを開く
- **THEN** 勘定科目/補助科目・取引先・部門・品目・タグ・自動仕訳ルール・取込口座・取込フォーマットを閲覧・編集できる

#### Scenario: 帳簿を管理する

- **WHEN** 帳簿のパネルを開く
- **THEN** 帳簿の一覧・作成・改名・アーカイブ・復帰ができる
- **AND** アーカイブ済みの帳簿を明示操作で表示できる
- **AND** 削除の導線は提供しない

#### Scenario: アーカイブの意味を示す

- **WHEN** 帳簿をアーカイブしようとする
- **THEN** データは削除されず一覧から下がるだけであること、いつでも復帰できることを示してから実行する

#### Scenario: 全データをエクスポートする

- **WHEN** データ管理から「エクスポート」を実行する
- **THEN** 現在対象になっている帳簿の zip をダウンロードする

#### Scenario: AI クライアントとの連携を設定する

- **WHEN** 設定画面から AI クライアント連携の導線を実行する
- **THEN** 導入用のバンドル（[[mcp-server]]）を書き出し、その場所を利用者に提示する
- **AND** 導入の手順と、連携後にできること・できないこと（承認は本アプリで行う）を示す

#### Scenario: 連携できているかを確かめられる

- **WHEN** 連携の導線を開く
- **THEN** 連携がまだ行われていないのか、既に設定済みなのかが区別できる形で示される
