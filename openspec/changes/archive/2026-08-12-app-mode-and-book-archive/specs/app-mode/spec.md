## Purpose

1インスタンスが「自分の帳簿1冊」と「顧問先 N 冊」という性質の異なる使われ方を持つため、
どちらとして振る舞うかを表す**アプリモード**を定める。モードは起動導線・UI の露出範囲・帳簿に関する不変条件のみを決め、
会計データの意味・計算結果・帳簿解決の可否は変えない。（[docs/architecture.md] §4/§5）

## ADDED Requirements

### Requirement: アプリモードの保持

システムは `personal`（じぶんの帳簿）と `office`（事務所）のいずれかをアプリモードとして control plane に保持する SHALL。
モードは帳簿を跨ぐアプリ全体の設定であり、個々の帳簿（data plane）には保存しない。

#### Scenario: モードを取得する

- **WHEN** `GET /api/app-mode` を呼ぶ
- **THEN** 現在のモード（`personal` / `office` / 未設定）を返す

#### Scenario: 未設定の状態を区別できる

- **WHEN** まだ一度もモードが選択されていない
- **THEN** 「未設定」を返し、既定値を勝手に確定しない（初回選択を促せるようにする）

#### Scenario: 帳簿を跨いで一つである

- **WHEN** 帳簿を切り替える
- **THEN** アプリモードは変わらない（帳簿ごとのモードは存在しない）

### Requirement: アプリモードの初回選択

システムはモードが未設定のとき、利用者に選択させてから業務操作へ進ませる SHALL。
選択は行為（何をしたいか）で提示し、選ばないまま既定へ流さない。

#### Scenario: 未設定なら選択を求める

- **WHEN** モードが未設定の状態でアプリを開く
- **THEN** モード選択を提示し、選択するまで業務画面へ進まない

#### Scenario: 選択を保存する

- **WHEN** 利用者がモードを選択する
- **THEN** `PUT /api/app-mode` で保存し、以降の起動では選択を求めない

### Requirement: アプリモードの変更

システムはモードをいつでも変更できる SHALL。変更は表示と導線のみを切り替え、
会計データに破壊的な副作用を持たない。

#### Scenario: 設定から変更する

- **WHEN** 利用者が設定画面でモードを変更する
- **THEN** 新しいモードを保存し、以降の起動導線と UI の露出範囲がそのモードに従う

#### Scenario: データを失わせない

- **WHEN** モードを変更する
- **THEN** 帳簿・仕訳・証憑はいっさい削除・改変されない（モード変更に伴うデータ処分は行わない）

#### Scenario: じぶんの帳簿へ変更するには1冊である必要がある

- **WHEN** アクティブな帳簿が2冊以上ある状態で `office` から `personal` へ変更しようとする
- **THEN** 変更を拒否し、アクティブな帳簿の一覧と帳簿管理への導線を返す（アーカイブして1冊にしてから変更する）

#### Scenario: 事務所へはいつでも変更できる

- **WHEN** `personal` から `office` へ変更する
- **THEN** 前提条件なく変更でき、隠れていた帳簿の作成・切替の導線が現れる

### Requirement: モードが定める帳簿の扱い

システムはモードに応じて、帳簿に関する不変条件と操作の可否を定める SHALL。

#### Scenario: じぶんの帳簿ではアクティブが常に1冊である

- **WHEN** モードが `personal` である
- **THEN** アクティブな帳簿はちょうど1冊であり、帳簿の作成を提供しない（不変条件が後から壊れない）

#### Scenario: じぶんの帳簿では帳簿を選ばせない

- **WHEN** モードが `personal` でアプリを開く
- **THEN** 唯一のアクティブ帳簿を対象とし、帳簿の選択・切替を求めない

#### Scenario: 事務所では必ず帳簿を選んでから始める

- **WHEN** モードが `office` でアプリを開く
- **THEN** 対象の帳簿（顧問先）を明示的に選ぶまで、いずれの帳簿も業務画面で開かない

#### Scenario: モードは帳簿解決の規約を上書きしない

- **WHEN** API リクエストの対象帳簿を解決する
- **THEN** 解決はヘッダ・クエリ・アクティブ1冊の暗黙解決という既存の規約のみに従い、モードによって変わらない
