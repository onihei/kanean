## Why

連携サービスの draft 一覧と取込明細で、1行が2行3行に折り返して読めない。

原因は幅の不足そのものではなく、**行に「全行で同じ値」を並べていること**にある。日付の年（一覧は
必ず開いている会計年度1つに閉じている）、相手科目（サービスを選んで見ている画面では常に同じ）、
確信度バッジの `確信度:` という前置き、取込明細の口座/形式列 — いずれも行ごとに変わらない。
変わらないものが行の幅を食い、変わるもの（摘要）が押し出されて折り返している。

さらに `flexWrap: 'wrap'` のため**折り返す位置が行ごとに動く**。2行になること自体より、
2行目の始まる x 座標が毎行違うことが可読性を落としている。目で追える列がどこにも無い。

計測（既定 Electron ウィンドウ 1280px）:

| | px |
|---|---:|
| ウィンドウ 1280 − サイドバー 220 − padding 64 | 内容 996 |
| − サービス一覧 240 − gap 16 | **詳細ペイン 740** |
| `DraftRow` が必要とする幅 | **約 1081** |

約 340px 超過している。`App.tsx` の `maxWidth: 1120` は main の実幅 1060 より大きいため
**既定ウィンドウでは制約として発動しておらず**、これを上げても既定サイズでは何も変わらない。

## What Changes

方針は一つ — **全行で同じ値は行から抜き、見出しへ移すか消す。例外だけ行に残す。**

- **日付**: 年を既定で表示せず `MM-DD` とする。ただし**開いている会計年度と異なる年の行だけ**
  年付きで表示する。年が消えることで、過年度の行が逆に目立つ（取込明細は会計年度に閉じておらず、
  繰越後は過年度の行が混ざりうる — その識別が無料で手に入る）
- **確信度バッジ**: `確信度: 高` → 色と `高`/`中`/`低` のみ。ラベル文字は全行同一で情報量ゼロ
- **金額表記**: `借 ¥3,280（相手: 普通預金）` → `−3,280`。借貸は符号で表し、相手科目は
  サービス見出し（`{accountName} / {accountRef}`）に既出のため行から落とす
- **税区分 select と税額**: 1行目から2行目（根拠行）へ移す。例外ベースレビューでは high を
  一括確定して medium/low だけ精査するため、これらは精査時にだけ要る情報である
- **勘定科目 select**: 閉状態に固定幅を与える（`<select>` は最長 option に幅が引きずられ、
  科目マスタが増えるほど行が広がる）。開いた一覧は全文のまま、切れる場合は `title` で補う
- **取込明細のテーブル**: `table-layout: fixed` ＋ `<colgroup>` で列幅を宣言し、摘要は
  省略記号＋`title` で全文を保持する。**行高が一定になる**ことが本題
- **`main` の `maxWidth: 1120`**: 引き上げる（任意・優先度低）。既定 1280 では不活性で、
  ウィンドウを広げて使う場合にのみ効く

削減の内訳（合計 −460px → 約 621px。740px に収まり、摘要に約 300px を割ける）:

| 変更 | 削減 |
|---|---:|
| 年を落とす | −44 |
| `確信度:` の4文字 | −42 |
| `借 …（相手: …）` を符号付き金額へ | −120 |
| 税区分 select を2行目へ | −172 |
| 税額を2行目へ | −82 |

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `web-app`: 一覧行の表記規則を追加する。日付から会計年度を省き、開いている会計年度と異なる
  行だけ年付きで示すこと、および行内で全行同一の値を重複表示しないことを要求に加える。
  既存 Requirement「例外ベースの取込レビュー」が求める情報（提案理由・確信度・証跡参照）は
  すべて表示したまま、配置だけを変える（削らない）。

## Impact

**変更するコード（`packages/web` のみ）**

- `src/lib/format.ts` — 一覧用の日付整形（開いている会計年度を受けて年の要否を決める）
- `src/pages/ServicesTab.tsx` — `DraftRow` / `ConfidenceBadge` の行レイアウト
- `src/pages/RawTransactionsTab.tsx` — テーブルの列幅宣言と摘要の省略
- `src/lib/styles.ts` — 固定幅 select・省略セルの共有スタイル
- `src/App.tsx` — `maxWidth`（任意）

**変更しないもの**

- サーバ API・DB スキーマ（表示のみの変更）
- 取込明細の会計年度スコープ化（`listRawTransactions` に年フィルタを足す話。別 change）
- `journalizeRow` の期間ゲート欠落（繰越後に日付と会計年度が食い違う仕訳を作れる不具合。別 issue）
- サイドバーの構造（19項目7グループは常設ナビ向きの規模。畳むと構造情報が失われる）
- 勘定科目 select の入力方式（科目数が多いのは一般的な会計ソフトと同様で、幅の問題は固定幅で解ける）
- 既定 Electron ウィンドウサイズ 1280×860（この change の受入基準がこのサイズで収まること）

**受入基準**

既定ウィンドウ 1280×860 で、連携サービスの draft 一覧と取込明細のどの行も意図しない折り返しを
起こさない（根拠行は意図した2行目であり折り返しではない）。
