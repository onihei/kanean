# filing-corner-assist — 確定申告書等作成コーナーへの転記による電子申告支援

## Why

申告書類の組成・PDF 出力（[[tax-return]]）までは実装済みだが、提出は紙前提のままで、
毎年の「作成コーナーへ数字を書き写す」作業が丸ごと利用者に残っている。
e-Tax の仕様は公開済みだがフル API 送信（送受信 API＋JPKI 署名）は重いため、
まず「アプリが決定的に作った転記値を、人（または利用者のサブスク範囲の Claude）が
国税庁の確定申告書等作成コーナーに転記して送信する」段を作る。
AI は転記の手に徹し、数字の正は core、送信と認証は人間に残す——という既存の役割分担
（アプリ＝台帳と決定的計算、Claude＝AI 労働力、MCP＝橋）をそのまま申告に延長する。

## What Changes

- server に**申告前チェック（precheck）**を追加する。青色控除の設定・決算整理・貸借の整合・
  未確定 draft・控除入力・消費税設定などの不備を決定的に判定して返す。
  「提出可能」は宣言しない（不備が見つからなかった、とだけ言う）。
- core/server で**入力指示書**を生成する。作成コーナーの画面順に「どの欄に何を入れるか」を
  並べた転記値一覧で、検算用に core が計算した最終税額（所得税・消費税）を含める。
  数字はすべて既存の tax-return 組成関数から来る（新しい計算はしない）。
- **申告の完了記録**を追加する。年分ごとに提出日・受付番号等を記録し、
  受信通知・申告書控え PDF を証憑として保存する。
- **MCP ブリッジ**に filing の動詞を追加する: precheck 取得・入力指示書取得・完了記録
  （読み取り2＋書き込み1）。転記の定型手順（作成コーナーの回り方・QR 認証と送信は人間・
  税額突き合わせ検算）は既存方針どおり **MCP 側から定型手順として配布**し、
  利用者に別途スキルを導入させない。
- **web に確定申告メニュー**を追加する。precheck 結果 → 入力指示書（コピー付き・手動転記の
  フォールバック）→ AI 転記の案内（MCP 疎通状態に応じて）→ 完了記録、の一連を提供する。
  アプリ単体（Claude なし）でも「チェック → 手動転記 → 完了記録」が完結する。

スコープ外（将来 change）: e-Tax フル API 送信（送受信 API・JPKI 署名）、xtx 書き出し、
eLTAX（住民税・事業税）、マイナポータル連携。ただし完了記録・指示書の形はこれらへ拡張できる形にする。

## Capabilities

### New Capabilities

- `filing`: 申告の提出支援。申告前チェック、作成コーナー向け入力指示書の生成、
  転記手順の配布（AI 転記時の人間介在点＝認証・送信ボタンの規約と税額突き合わせ検算を含む）、
  申告の完了記録と控え PDF の証憑保存。

### Modified Capabilities

- `mcp-server`: 露出する動詞の範囲に filing の読み取り（precheck・入力指示書）を加え、
  書き込みの限定列挙に「申告の完了記録（受付番号・控え PDF の添付）」を加える。
  定型手順の配布に「確定申告の転記」入口を加える。
- `web-app`: 業務メニューに確定申告画面を加える（precheck 表示・入力指示書の閲覧とコピー・
  AI 転記の案内・完了記録）。

## Impact

- `packages/core`: 新規計算なし。既存の税額組成の出力を入力指示書へ射影する純関数を追加。
- `packages/server`: `/api/filing/*`（precheck・入力指示書・完了記録・控え添付）。
  data plane に完了記録テーブルを追加（マイグレーション）。
- `packages/mcp`: filing ツール3種＋定型手順（prompt）1本。版一致の既存規約に乗る。
- `packages/web`: 確定申告メニュー（新画面）。ナビゲーションへの追加。
- `docs/`: 作成コーナーとの欄対応は `docs/filing-corner-mapping.md` を新設して正とする
  （form-mapping.md の様式ボックスを作成コーナー画面へ対応づける）。
- 依存追加なし。ブラウザ操作はクライアント（Claude Desktop 側の機能）に委ね、アプリは持たない。
- `legalRisk:high` の原則は不変: システムも AI も「提出可能」を宣言せず、送信は人間が行う。
