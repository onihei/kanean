# 減価償却計算仕様 — Kanean

> [data-model.md](./data-model.md) の `fixed_assets` / `depreciation_entries` と [accounting-spec.md](./accounting-spec.md) §8 を具体化する。
> 主軸は **定額法（新定額法）**。利用者は定額法のみ使用するが、データモデルが対応する他方式も定義する。
>
> ⚠️ 償却率表・各種基準額は税制で変わる（PRD R-3）。本書の数値は基準値とし、実装では**有効期間付き外部データ**で持つ。

## 1. 適用区分（どの資産をどう処理するか）

取得価額と選択により処理が分かれる。`fixed_assets.depreciation_method` で表現。

| 取得価額 | 既定の扱い | method | 償却 |
|---|---|---|---|
| 10万円未満 | 少額の減価償却資産 → 即時経費（消耗品費等） | （台帳対象外） | しない |
| 10万円以上 20万円未満 | 一括償却資産（選択可） | `lump_sum` | 3年均等（§5） |
| 30万円未満 | 少額減価償却資産特例（青色・中小、年300万まで） | `minor_special` | 即時経費（§6） |
| 上記によらず資産計上 | 通常償却 | `straight_line`(定額) / `declining_balance`(定率) | §2 / §4 |

> 本利用者は **`straight_line`（定額法）** を使用。少額特例（30万未満）も選択可能だが、台帳に計上して定額償却する運用も可（参照データの Mac/iPhone/ドローンは資産計上の例）。

## 2. 定額法（新定額法）— 主軸

対象: **2007/4/1 以後取得**の資産。

### 2.1 基本式
```
普通償却費(年額) = 取得価額 × 定額法償却率
```
- 償却率は耐用年数から決まる（§3 償却率表）。`fixed_assets.depreciation_rate` に保持。
- **取得価額を基準**に毎年同額を償却（期首帳簿価額基準ではない）。

### 2.2 初年度の月割
事業供用開始日（`business_start_date`）の属する月から期末までの月数で按分。

```
初年度償却費 = ⌈ 取得価額 × 償却率 × (供用月数 / 12) ⌉   ← 円未満は切上げ
供用月数 = 事業供用開始日の属する月 〜 期末月（端数日は1月に切上げ）
```
> 例: 7/11事業供用・暦年 → 7〜12月 = 6月 → ×6/12。
> **月割償却費の円未満は切上げ**（実データ準拠）。検算: マツダ2 初年度 1,508,300×0.5×5/12=314,229.17 → **314,230**（切捨て314,229では1円ずれる）。満額年（12ヶ月）の円未満は切捨て（§9）。

### 2.3 最終年（備忘価額1円）★利用者の質問の核心
償却を続け、**未償却残高が「取得価額×償却率」を下回る最終年は、帳簿価額を1円残して償却**する。

```
通常年:   償却費 = 取得価額 × 償却率
最終年:   償却費 = 期首未償却残高 − 1
          （未償却残高が 1円 になるまで償却。1円＝備忘価額は除却まで残す）
```
- これにより資産は0円ではなく**1円**で台帳に残り続ける（存在の記録）。
- 除却・売却時にこの1円を落とす（§7）。

### 2.4 事業利用比率の扱い（確認済み方針）
**償却費そのもの（＝未償却残高の減少）は全額**。事業利用比率は**必要経費算入額にのみ**掛ける。

```
本年分償却費(全額)      = §2.1〜2.3 で算出
家事分（経費不算入）    = 本年分償却費 × (1 − 事業利用比率/100)   （端数は円未満切捨て）
必要経費算入額          = 本年分償却費 − 家事分                  （＝端数は経費側に寄る）
期末未償却残高          = 期首未償却残高 − 本年分償却費(全額)   ← 按分前の全額で減らす
```
> **按分の端数規約**: 家事按分(§6)と統一し、**家事分を円未満切捨て・必要経費＝残り**とする（実データ準拠）。
> 「必要経費＝償却費×比率を切捨て」では §2.5 の実データと1円ずれるため採らない（マツダ2: 家事分 floor(439,919×0.5)=219,959 → 必要経費 219,960）。
> `depreciation_entries`: `depreciation_amount`=本年分償却費(全額)、`business_amount`=必要経費算入額、`closing_book_value`=期末未償却残高。

### 2.5 検算（参照データ マツダ2／事業利用50%）
| 項目 | 値 |
|---|---|
| 今期償却前残高（期首） | 439,920 |
| 本年分償却費（全額・最終年） | **439,919**（= 439,920 − 1） |
| 必要経費算入額（×50%） | **219,960**（439,919×50%=219,959.5 → 円処理） |
| 今期償却後残高 | **1**（備忘価額） |

→ 参照データ（償却439,919・経費算入219,960・残高1）と**一致**。§2.3〜2.4の方針が正しいことを確認。

## 3. 定額法 償却率表（抜粋・外部データ化）

`耐用年数 → 定額法償却率`。実装では全年数を外部テーブルで保持し、取得日で適用版を切替。

| 耐用年数 | 償却率 | | 耐用年数 | 償却率 |
|---|---|---|---|---|
| 2年 | 0.500 | | 8年 | 0.125 |
| 3年 | 0.334 | | 9年 | 0.112 |
| 4年 | 0.250 | | 10年 | 0.100 |
| 5年 | 0.200 | | 15年 | 0.067 |
| 6年 | 0.167 | | 20年 | 0.050 |
| 7年 | 0.143 | | … | … |

> 耐用年数は資産種類で決まる（耐用年数省令）。例: PC=4年、一般工具器具備品・カメラ等、普通自動車=6年、軽自動車=4年。耐用年数表も外部データ化。

### 3.1 中古資産の簡便法（見積耐用年数）

中古で取得した資産は、法定耐用年数ではなく簡便法で見積耐用年数を算定できる（耐用年数省令§3・
国税庁 No.5404）。**実装済**（core `usedAssetUsefulLife(法定耐用年数, 経過月数)`）。

```
法定耐用年数の全部を経過: 見積耐用年数 = 法定耐用年数 × 20%
法定耐用年数の一部を経過: 見積耐用年数 = （法定耐用年数 − 経過年数）＋ 経過年数 × 20%
→ 1年未満の端数は切捨て、2年未満は2年。経過は月数で計算してから年に換算。
```
- 例（参照データ マツダ2 相当）: 法定6年(72月)・経過46月 → (72−46)+46×0.2 = 35.2月 → 2.93年
  → **2年**（切捨て）。全部経過（≧72月）なら 72×0.2 = 14.4月 → 1.2年 → 最低 **2年**。
- ⚠️ legalRisk:high（経過年数の事実認定・簡便法の適用可否は税理士サインオフ対象）。
- 見積耐用年数は `fixed_assets.useful_life` に格納し、以降は通常の定額法/定率法で償却する。

## 4. 定率法（200%定率法）

対象: 2012/4/1 以後取得。**実装済**（Phase5・core `decliningBalanceSchedule` / `DECLINING_BALANCE_RATES`）。

```
償却費 = 期首帳簿価額 × 定率法償却率
ただし 償却費 < 償却保証額(= 取得価額 × 保証率) となった年以降:
  償却費 = 改定取得価額（その年の期首帳簿価額）× 改定償却率   （以後均等、1円まで）
```
- **定率法償却率は耐用年数 n に対し `2/n` を小数3桁に丸めた公示値**（国税庁別表第十）。
  §3 の丸め済み定額法償却率を単純に2倍した値ではない（例: 6年は `2/6=0.3333…→0.333`。
  定額法率0.167の2倍0.334ではない）。`保証率`・`改定償却率`も耐用年数ごとの公示値。
- 初年度月割は定額法と同様（供用月数で按分・円未満切上げ §2.2/§9）。
- 事業利用比率・1円備忘の扱いは定額法と同じ（§2.3〜2.4）。

## 5. 一括償却資産（`lump_sum`）

取得価額 10万円以上 20万円未満を選択した場合。

```
本年分償却費 = 取得価額 × 1/3   （3年間均等）
```
- **月割しない**（事業供用月に関わらず取得価額の1/3）。
- 3年で**全額償却（残高0、備忘1円を残さない）**。
- 年の途中で除却しても3年償却を継続（除却損は計上しない）。**実装済**（除却は `status=retired` の記録のみで除却損仕訳を起票せず、期末償却が3年枠内で継続。Phase5 slice6・§10.3）。
- 事業利用比率の按分は行わない運用が一般的（全額が3分の1ずつ経費）。
- 償却資産税（地方税）の対象外という利点。

## 6. 少額減価償却資産特例（`minor_special`）

青色・中小事業者、取得価額30万円未満、**年間合計300万円まで**。

```
本年分必要経費算入額 = 取得価額（× 事業利用比率/100）   ← 取得年に全額
```
- 取得年に全額を必要経費（減価償却費 or 消耗品費）に算入。
- 固定資産台帳・減価償却明細には記載し、摘要に根拠（措法28の2）を付す。
- 年間合計300万円の上限チェックが必要（超過分は通常償却）。

## 7. 除却・売却（`retired_date` あり）

| 事象 | 処理 |
|---|---|
| 除却 | 除却時の未償却残高（按分後の事業分相当）を除却損へ。期中除却は供用月数で当期償却後の残高を算定 |
| 除却（一括償却資産） | **例外**: `lump_sum` は除却損を計上せず3年均等償却を継続（§5）。除却は `status=retired` の記録のみで仕訳を起票せず、期末償却が3年枠内で継続する |
| 売却 | **個人事業では譲渡所得**（事業所得と別計算）。売却損益は譲渡所得で処理（手計算・スコープ外）、帳簿上は未償却残高を**全額 事業主貸へ振替**（除却損は計上しない）。参照CSVの「資産譲渡損（事業主貸）」科目に対応。**実装済**（Phase5 slice7・`sellFixedAsset`・`status=sold`。期中売却は供用月数で当期償却後の残高を振替・一括償却は所令§139で売却後も3年継続） |

> 売却の所得区分（譲渡所得）は事業所得の損益計算書には含めない点に注意。**譲渡所得の計算（売却代金・取得費・譲渡損益）は本システムのスコープ外（手計算/別途）**とし、台帳側＝未償却残高の事業主貸への振替のみを自動化する（Phase5 slice7。除却は除却損を計上＝事業所得、売却は事業主貸振替＝損益は譲渡所得へ、で区分）。

## 8. 仕訳生成（期末）

`depreciation_entries` 確定時に、必要経費算入額で償却仕訳を生成（`journal_entries.source='depreciation'`）。記帳方法（`business_settings.depreciation_record_method`）で貸方を切替。

```
直接法:  借) 減価償却費  business_amount  /  貸) 対象資産科目  business_amount
間接法:  借) 減価償却費  business_amount  /  貸) 減価償却累計額 business_amount
```
- 摘要は `reflect_name_to_description=1` なら資産名で上書き。
- 家事分（償却費−経費算入額）は仕訳しない（経費に計上しないだけ。帳簿価額は別途台帳で全額管理）。
  - ※直接法で資産科目を全額落としたい場合の扱いは実装方針として §10 で要確定（台帳の未償却残高は全額ベース、仕訳の経費は按分後）。

## 9. 端数処理

| 対象 | 規則 |
|---|---|
| 償却費・満額年（取得価額×償却率） | 円未満切捨て |
| 償却費・初年度の月割 | **円未満切上げ**（実データ準拠・§2.2） |
| 償却費・除却年度の月割（§7） | **円未満切上げ**（初年度月割と同規約。期首〜除却月で按分。legalRisk:high・税理士確認） |
| 月割 | 月数は端数日を1月に切上げ |
| 家事分（×(1−事業利用比率)） | 円未満切捨て。**必要経費算入額＝償却費−家事分**（§2.4） |
| 備忘価額 | 最終年に1円を必ず残す |
