# 会計仕様書 — Kanean

> [data-model.md](./data-model.md) の計算ロジックの正解を定義する。
> 対象: 個人事業主・青色申告（複式簿記）・消費税は課税事業者の**簡易課税**・税込経理・固定資産・家事按分。
>
> ⚠️ **税率・みなし仕入率・源泉税率・経過措置は税制改正で変わる**（PRD R-3）。本書の数値は仕様の基準値として記すが、
> 実装では `tax_categories` / 率テーブル等に**外部データ化**し、適用期間（有効開始日）で切替できるようにする。

## 1. 複式簿記の基本ルール

### 1.1 仕訳の構造
- 1仕訳（`journal_entries`）は1つ以上の明細（`journal_lines`）を持つ。
- 各明細は `side ∈ {debit(借方), credit(貸方)}`。
- **整合性ルール（必須）**: 1仕訳内で `Σ(借方金額) = Σ(貸方金額)`。不一致は confirmed 化を禁止。
- 複合仕訳（借方N:貸方M）を許容（源泉徴収・税抜経理・按分等で必要）。

### 1.2 勘定科目の貸借区分（`accounts.normal_balance` 決定規則）
通常残高がどちら側に出るかを、`report_type` + `section` から機械的に決める。

| report_type | section | normal_balance | 増加時 |
|---|---|---|---|
| BS | 流動資産 / 固定資産 / 繰延資産 | **debit** | 借方 |
| BS | 流動負債 / 固定負債 | **credit** | 貸方 |
| BS | 資本（元入金 等） | **credit** | 貸方 |
| PL | 売上（収入）金額 | **credit** | 貸方 |
| PL | 売上原価 / 経費 | **debit** | 借方 |

#### 1.2.1 例外（評価勘定・特殊科目）
科目名で個別指定（シード時に `normal_balance` を明示）。

| 科目 | 区分 | normal_balance | 備考 |
|---|---|---|---|
| 減価償却累計額 | 資産の評価勘定（控除） | **credit** | 資産のマイナス |
| 貸倒引当金 | 資産の評価勘定（控除） | **credit** | |
| 事業主貸 | 資本の控除（引出） | **debit** | 個人事業特有。期末に元入金へ振替 |
| 事業主借 | 資本（拠出） | **credit** | 同上 |
| 売上値引・返品 | 売上の控除 | **debit** | 収益のマイナス |
| 仕入値引・返品 | 仕入の控除 | **credit** | 費用のマイナス |

> 試算表・元帳の残高 = `Σ借方 − Σ貸方`（normal_balance=debit）または `Σ貸方 − Σ借方`（credit）。

### 1.3 個人事業特有の期末処理
- **事業主貸／事業主借／控除前所得金額** を期末に **元入金** へ振り替える（翌期首の元入金 = 前期末元入金 + 当期所得 + 事業主借 − 事業主貸）。
- これにより翌期開始残高（`opening_balances`）の元入金が決まる。
- **繰越の粒度**: 資産・負債の期末残高は**補助科目別**に翌期 `opening_balances` へ繰越す（補助科目なしの残高は補助NULL行、元入金は補助なし1行）。売掛金の取引先別残高（[data-model §2.5]）など補助元帳の期首繰越が翌期へ引き継がれる。補助別残高が相殺して科目残高が0でも補助行は繰越す（過入金の貸残等を保持）。
- 決算書(貸借)の資本の部「控除前所得金額」= 損益計算書の当期所得（連結算出行）。
- **取込との関係**: データ取込は**開いている会計期間（`fiscal_years.status='open'`）の取引のみ**を対象とし、翌期分は取り込まない。この**年度繰越処理で翌期が open になって初めて翌期の取引が取込対象**になる（[csv-format C-8] / [acquisition-skill-spec §5]）。

## 2. 消費税 — 税区分マスタ（`tax_categories` 全コード定義）

### 2.1 コード体系
`code` の命名規則（実装の一意キー）:
```
{方向}_{税率}_{区分}[_{調整}]
  方向: SALE(課売) / PUR(課仕) / NONTAX(非) / OUT(対象外)
  税率: 10 / 8 / 0
  区分: C1..C6（簡易課税 事業区分。売上系のみ）
  調整: RET(返還・値引) / BAD(貸倒)
```

### 2.2 標準シード（情報通信＝第5種を主に使用・**14件に最小化**）
商用SaaSは本則課税・全事業区分・軽減・輸入・有価証券・回収まで網羅し約80区分あるが、本利用者（簡易課税・第5種・税込経理）に必要なのは下記のみ。
**8% は軽減税率**（恒久制度。飲食料品〔外食・酒類除く〕と定期購読新聞）。現行標準は10%。

| code | label | taxability | direction | rate | simplified_category | adjustment |
|---|---|---|---|---|---|---|
| `SALE_10_C5` | 課売 10% 五種 | taxable | sale | 10 | 第5種 | none |
| `SALE_8_C5` | 課売 (軽)8% 五種 | taxable | sale | 8 | 第5種 | none |
| `SALE_10_C5_RET` | 課売-返還 10% 五種 | taxable | sale | 10 | 第5種 | return |
| `SALE_8_C5_RET` | 課売-返還 (軽)8% 五種 | taxable | sale | 8 | 第5種 | return |
| `SALE_10_C5_BAD` | 課売-貸倒 10% 五種 | taxable | sale | 10 | 第5種 | bad_debt |
| `SALE_8_C5_BAD` | 課売-貸倒 (軽)8% 五種 | taxable | sale | 8 | 第5種 | bad_debt |
| `PUR_10` | 課仕 10% | taxable | purchase | 10 | – | none |
| `PUR_8` | 課仕 (軽)8% | taxable | purchase | 8 | – | none |
| `PUR_10_RET` | 課仕-返還 10% | taxable | purchase | 10 | – | return |
| `PUR_8_RET` | 課仕-返還 (軽)8% | taxable | purchase | 8 | – | return |
| `NONTAX_SALE` | 非売 | non_taxable | sale | 0 | – | none |
| `NONTAX_PUR` | 非仕 | non_taxable | purchase | 0 | – | none |
| `OUT` | 対象外 | out_of_scope | none | NULL | – | none |
| `OUT_PUR` | 対象外仕 | out_of_scope | purchase | NULL | – | none |

> 注:
> - **勘定科目の既定税区分は現行標準10%に寄せる**（参照チャートは旧8%既定だが現行は10%）。軽減8%は飲食料品・定期新聞のみで、情報通信業の売上には出てこない。
> - **簡易課税では仕入の税区分は納税額計算に影響しない**（控除はみなし仕入率で計算）。`PUR_*` は記帳・インボイス記録用。
> - 軽減8%は**恒久制度**で「終わった移行措置」ではない。旧標準8%(2014–2019)・旧税率(5%・3%)は過年度データ取込時のみ必要になれば追加。
> - 第1〜4種・第6種を使う場合は `C1..C4, C6` の売上コードを追加（事業区分が混在する事業者向け）。

### 2.3 軽減税率の扱い
- 税率は明細単位（`journal_lines.tax_category_id` / `document_lines.tax_rate`）で 10% / 8% を区別。
- 標準10%（国7.8%＋地方2.2%）、軽減8%（国6.24%＋地方1.76%）。申告計算上は税率ごとに区分して集計。

## 3. 消費税の計算（簡易課税）

### 3.1 みなし仕入率（事業区分別）
| 事業区分 | 業種例 | みなし仕入率 |
|---|---|---|
| 第1種 | 卸売業 | 90% |
| 第2種 | 小売業、飲食料品の譲渡に係る農林漁業 | 80% |
| 第3種 | 製造業・建設業・農林漁業 等 | 70% |
| 第4種 | 飲食店業・その他の事業 | 60% |
| **第5種** | **サービス業・情報通信業 等** | **50%** |
| 第6種 | 不動産業 | 40% |

> 本利用者（情報通信）は **第5種＝50%**。`business_settings.tax_business_category` の既定。

### 3.2 納付税額の計算
税率ごと（10% / 8%）に区分して計算し合算する。

```
課税標準額          = 課税売上(税抜) の合計（税率別）
売上に係る消費税額  = 課税標準額 × 税率（国税分は税率の国税割合を使用）
控除対象仕入税額    = 売上に係る消費税額 × みなし仕入率
（返還等対価に係る税額・貸倒れに係る税額を調整）
納付税額(国税)      = 売上に係る消費税額 − 控除対象仕入税額 − 返還等 − 貸倒
地方消費税          = 国税額 × (地方割合 / 国税割合)  ※税率体系に従う
納付税額(合計)      = 国税 + 地方
```
- **複数事業区分が混在**する場合は、区分ごとの売上割合で加重平均（75%ルール等の特例あり）。MVPは単一区分（第5種）前提で実装し、複数区分は将来対応。

### 3.3 インボイス経過措置（2割特例）— 条件付き
- 免税事業者がインボイス登録で課税事業者になった場合、令和5年10月〜令和8年9月を含む課税期間は **納付税額 = 売上に係る消費税額 × 20%** を選択可。
- **本利用者は従来から課税事業者のため対象外の見込み**。ただし制度として `tax_method` に `two_percent_special` を将来追加できる余地を残す（適用判定は申告時に選択）。

### 3.4 申告対象期間
- 課税期間 = 会計期間（`fiscal_years`）。個人は暦年（1/1〜12/31）が原則。

## 4. 経理方式と端数処理

### 4.1 経理方式（`accounting_method`）
| 方式 | 記帳 | 仮払/仮受消費税 |
|---|---|---|
| **税込経理（既定）** | 消費税込みの金額で記帳 | 使わない。`tax_amount` は集計・申告用に内部保持 |
| 税抜経理 | 本体と消費税を分離記帳 | 課税仕入→仮払消費税、課税売上→仮受消費税を計上 |

> **簡易課税では仕入税額を実額計算しない**ため、税抜経理の実益が小さい。本利用者は**税込経理**を既定とする。

### 4.2 消費税額の算出と端数処理（`rounding_sales` / `rounding_purchase`）
- 明細の消費税額 `tax_amount`:
  - 税込経理: `tax_amount = 金額 − 金額 ÷ (1 + rate/100)`（税込から内税を逆算）
  - 税抜経理: `tax_amount = 本体 × rate/100`
- 端数処理は **設定値（floor=切捨／round=四捨五入／ceil=切上）** を適用。既定は売上・仕入とも `floor`（切捨）。
- **インボイス対応**: 適格請求書では「1インボイスにつき税率ごとに1回」の端数処理。請求書発行時は `documents` 単位・税率別に1回だけ端数処理する。

## 5. 源泉徴収（報酬・料金）

### 5.1 税率
| 区分 | 税率 |
|---|---|
| 報酬・料金（1回の支払 100万円以下の部分） | **10.21%**（所得税10% + 復興特別所得税0.21%） |
| 100万円を超える部分 | **20.42%** |

```
源泉徴収税額 = min(支払額, 1,000,000) × 10.21%
             + max(支払額 − 1,000,000, 0) × 20.42%
```
- 消費税額が請求書で明確に区分されている場合は、**税抜（本体）金額**を源泉計算の基礎にできる（区分しない場合は税込基礎）。
- 端数は円未満切捨て。

### 5.2 仕訳（売上を受け取る側＝個人事業主）
源泉された所得税は **事業主貸（源泉所得税）** で処理し、確定申告で精算する。

例: 報酬110,000円（税込、源泉対象、本体100,000・消費税10,000）、源泉10,210円
```
借) 普通預金            99,790
借) 事業主貸(源泉所得税) 10,210   /  貸) 売上  110,000
```
> `document_lines.withholding` が立つ請求書から、この複合仕訳を自動生成（売上計上日 = `revenue_recognition_date`）。

## 6. 租税公課と税金の処理区分

個人事業主が支払う税金は「必要経費（**租税公課**）になるもの」と「事業の損益に入らない（**事業主貸**）もの」に分かれる。預金利息の源泉も損益外。

| 税金 | 勘定 | 備考 |
|---|---|---|
| 自動車税・軽自動車税 | **租税公課**（家事按分対象） | 事業按分分のみ経費。家事分は事業主貸（§7で按分） |
| 固定資産税・償却資産税 | 租税公課（按分可） | 自宅兼事務所等は事業供用分のみ |
| 印紙税・登録免許税・個人事業税 | 租税公課 | 事業に係るもの |
| **消費税の納付額（税込経理）** | **租税公課** | 税込経理では納付消費税を租税公課で計上（税抜経理なら未払消費税の精算）。簡易課税の算出は §3 |
| 所得税（本税・予定納税） | **事業主貸** | 損益外。個人の所得にかかる税 |
| 住民税 | 事業主貸 | 同上 |
| 預金利息の源泉（国税=所得税15.315%、地方税=利子割5%） | **事業主貸** | 利子所得への源泉。事業の損益外（§5 / csv-format §3.2） |
| 加算税・延滞税・各種罰金 | 事業主貸 | 必要経費不算入 |

- **自動車税の按分**: 自動車税は**請求書払いで取込元に連携されない**ため手動入力。取込時の自動仕訳（連携時）は全額を租税公課で提案するが、実際は事業利用比率で按分する。家事按分（§7）の対象科目に租税公課（自動車税の補助科目）を含め、家事分を事業主貸へ振り替える。
- **消費税の納付は銀行（UFJ）で連携**され、摘要 `税金 シヨウヒゼイ` で識別（→租税公課。csv-format §5）。新生の摘要「国税」は消費税でなく利息の所得税源泉なので混同しない（→事業主貸）。
- 受取利息の本体は **事業主借**（損益外）、その源泉（国税・地方税）は **事業主貸**。法人と異なり受取利息勘定は使わない。

## 7. 家事按分の計算

### 6.1 ロジック
- 対象科目（`proration_settings.account_id`、補助科目NULL=全補助科目）について、当期の経費計上額を集計。
- `事業利用比率(business_ratio)` を掛けた額が**事業経費**、残りが**家事分**。
```
家事分 = 経費計上額 × (1 − business_ratio/100)   ※端数は切捨て
```
### 6.2 仕訳（期末一括 `year_end` の場合）
家事分を経費から控除する振替（`source='proration'`）。
```
借) 事業主貸   家事分   /  貸) 対象経費科目（例: 水道光熱費）家事分
```
- `method='each'`（都度）の場合は取引ごとに按分後の額で計上。
- 按分は**申告項目ではなく仕訳結果**として損益に反映（data-model M-8）。
- 再計算時は当該年度の `source='proration'` 仕訳を再生成（洗い替え）。

## 8. 減価償却（概要・詳細は別仕様）

- 償却方法: 定額法 / 定率法 / 一括償却資産（3年均等）/ 少額減価償却資産特例（即時経費）。
- 事業利用比率を掛けた額が必要経費算入額（`depreciation_entries.business_amount`）。
- 期末に償却仕訳を生成（記帳方法 直接法/間接法で貸方科目を切替）:
  - 直接法: `借) 減価償却費 / 貸) 対象資産`
  - 間接法: `借) 減価償却費 / 貸) 減価償却累計額`
- 償却率・改定償却率・保証率・月割計算は **「減価償却計算仕様」** で定義（耐用年数表を外部データ化）。

## 9. 帳簿・残高の算出ルール

| 帳簿 | 算出 |
|---|---|
| 総勘定元帳の残高 | 科目（+補助）ごとに時系列で `normal_balance` 方向に累積 |
| 試算表（合計残高試算表） | 全科目の借方合計・貸方合計・残高 |
| 損益計算書 | PL科目を section（売上/売上原価/経費）で集計、当期所得を算出 |
| 貸借対照表 | BS科目を section で集計、資本の部に控除前所得金額を連結 |
| 消費税集計 | confirmed 仕訳の `tax_category` 別に課税売上・税額を集計（§3） |

> すべて `journal_entries.status='confirmed'` のみを対象（draftは除外。data-model D-10）。
